# 🌍 Səyahət və Turizm Məlumatlarının Təhlili (Travel & Tourism Data Analysis)

Bu layihə Səyahət və Turizm datasetinin ilkin kəşfiyyatı və analizi (EDA) məqsədilə hazırlanıb. Məqsəd Python vasitəsilə səyahət rezervasiyaları tendensiyalarını, müştəri demoqrafiyasını, maliyyə xərclərini və otel reytinqlərini təmizləmək, təhlil etmək və vizuallaşdırmaqdır.

## 🚀 İstifadə Olunan Texnologiyalar
* **Python**
* **Pandas** (Məlumatların idarə edilməsi və təhlili)
* **Matplotlib & Seaborn** (Məlumatların vizuallaşdırılması)

## 📊 Əsas Nəticələr və Tapıntılar
* **Demoqrafiya:** Cinsiyyət bölgüsündə səyahətçilərin 56.8%-i qadın, 43.2%-i isə kişilərdir.
* **Top İstiqamətlər:** Hindistan 669 rezervasiya ilə əsas ölkədir; Kolombo, Şimla və Rişikeş ən çox seçilən şəhərlər sırasındadır.
* **Maliyyə:** Ümumi səyahət xərcləri 11,000 ilə 1.6M arasında dəyişir ki, bu da büdcəli və lüks səyahət seqmentlərini aydın göstərir.
* **Reytinqlər:** Otel və müştəri reytinqləri təhlil edilərək rəy bildirməyən istifadəçilər və ümumi qiymətləndirmə mənzərəsi aşkarlanıb.

## 📂 Layihənin Strukturu
* `Travel And Tourism.csv` - Analiz üçün istifadə olunan dataset.
* `analysis.py` - Məlumatların işlənməsi, statistika və vizuallaşdırma kodlarını ehtiva edən Python skripti.
* `hotel_ratings.png` - Yaradılan vizual qrafik.
